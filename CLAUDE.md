# LabLens

LabLens is a gesture-controlled chemistry lab demo that uses a webcam and hand tracking to let a student "load" virtual chemicals onto their fingertip and combine them to trigger reactions. It features a finger-glow AR effect, reaction triggering, an info panel (displaying equation, observation, and exam-relevance tags), and a simplified periodic table interface.

## Tech Stack
- OpenCV
- MediaPipe
- NumPy
- Pillow
- SQLite
(Single process, no Electron/Pygame/Postgres/FAISS)

## Build Status
- **Phase 1 (Setup)**: Initialized project structure, created `main.py` with basic OpenCV webcam loop, set up requirements and virtual environment. Verified webcam feed works.
- **Phase 2 (Gestures)**: Implemented MediaPipe Hands wrapper (`gestures.py`) for tracking one hand and classifying HOVER, FIST, and WASH_OFF gestures with debouncing. Integrated live pipeline in `main.py`.
- **Phase 3 (Data)**: Created `data.py` to seed a SQLite database (`lablens.db`) with 20 standard NCERT/JEE inorganic chemistry reactions and ~30 relevant elements.
- **Phase 4 (UI)**: Added `ui.py` to draw the three-zone interface (Chemical Panel, Reaction Zone, Info Panel) with Pillow. Integrated with `main.py` to perform hit-testing and visualize hovered chemicals.
- **Phase 5 (Glow Effect)**: Added `glow.py` to alpha-blend a feathered glow around the fingertip when a chemical is "loaded". Implemented the DIP event on entry and handled WASH_OFF state clearing.
- **Phase 6 (Reactions & Info Panel)**: Added `reactions.py` to evaluate reactant combinations via SQLite, and to render 1.5-second OpenCV animations when a COMBINE event triggers. FIST resets the beaker. Info panel populates with the balanced equation, observations, conditions, and color-coded exam-relevance tag upon reaction completion. The core demo loop is complete.
- **Phase 7 (Periodic Table)**: Added `periodic_ui.py` to render a secondary mode with a simplified Periodic Table grid based on seeded elements. Uses FIST to toggle between Reaction Lab and Periodic Table modes. Supports hover-tooltips and hold-to-expand character cards.
- **Phase 8 (AI Examiner)**: Added `ai_examiner.py` using the `anthropic` SDK. Tapping 'a' when a reaction is complete generates a context-bounded Socratic question using `claude-sonnet-4-6`. The question displays in the Info Panel.

## File/Module Map
- `main.py`: Entry point, holds the camera loop and app state machine.
- `gestures.py`: MediaPipe wrapper for hand tracking and gesture classification.
- `ui.py`: Renders the three-zone UI overlay with OpenCV and Pillow.
- `glow.py`: Applies visual feathered glow effects based on the loaded chemical's color.
- `reactions.py`: Evaluates loaded chemicals and renders animated results over the beaker.
- `data.py`: Script to initialize and seed the SQLite database.
- `lablens.db`: SQLite database holding elements and reactions (generated by `data.py`).
- `requirements.txt`: Python dependencies.
- `README.md`: Project overview and setup instructions.
- `.gitignore`: Git ignore rules.
- `CLAUDE.md`: AI assistant context and project documentation.
- **Phase 9 (Polish)**: Adjusted gesture thresholds, added database/webcam error handling, and created comprehensive documentation (`README.md`, `DEMO.md`). Build complete.

## Build vs Full Spec (v1 vs v2)
This marks the completion of the LabLens v1 demo build. Below is an honest comparison of what is in this build versus the original full specification, highlighting what a potential v2 should address:

**Implemented in v1:**
- Hand tracking via MediaPipe (index finger pointer)
- Hover-to-select Reagent and Equipment pickers
- Visual DIP loading with color-coded fingertip glow
- Beaker hit-testing to COMBINE chemicals
- 20 seeded NCERT/JEE reactions (gas, precipitate, colour change, exothermic animations)
- Info panel displaying equation, observation, conditions, and exam relevance
- Universal discrete gestures: WASH_OFF (open palm swipe) and FIST (mode toggle / beaker reset)
- Periodic Table mode with grid layout, hover-tooltips, and hold-to-expand character cards
- AI Examiner integration via Anthropic (manual trigger bounding the AI context)

**Omitted / Deferred to v2:**
- Full 400+ reaction database (v1 uses 20 seeded reactions)
- Continuous pinch-zoom logic for 3D molecular inspection
- "Exceptions Hall" UI for anomalous electron configurations
- Advanced apparatus handling (physically lifting/pouring from test tubes rather than point-and-click UI logic)
- RAG-bounded Vector Store for the Examiner (v1 uses simplified single-record context passing)
