# LabLens Project Structure

Below is the complete file and directory structure of the LabLens application, including the purpose and type of each file.

```text
LabLens/
│
├── 📂 static/                        # Frontend Directory (Served to the browser)
│   ├── 📄 index.html                 # [HTML] The main web page structure. Defines the UI layout, camera container, beaker SVG, and loads the MediaPipe tracking libraries.
│   ├── 📄 style.css                  # [CSS] The stylesheet controlling the visual theme (dark blue palette), layout, animations, and responsive scaling.
│   ├── 📄 app.js                     # [JavaScript] The core frontend logic. Handles webcam access, MediaPipe hand tracking, gesture math (Fist, Wave, Pinch, High-Five), and API calls to the backend.
│   ├── 🖼️ chem.png                   # [Image] Icon graphic used for the Reagents Picker in the top-left corner.
│   └── 🖼️ cone.png                   # [Image] Icon graphic used for the Equipment Basket.
│
├── 📄 app.py                         # [Python] The FastAPI backend server. It serves the static files to the browser and exposes API endpoints (`/api/chemicals`, `/api/react`, `/api/examine`) for the frontend to communicate with the database and AI.
├── 📄 data.py                        # [Python] A database initialization script. When run, it creates `lablens.db` and populates it with all 118 elements and 20+ predefined chemical reactions.
├── 🗄️ lablens.db                   # [SQLite] The local database file generated by `data.py`. Stores element properties and reaction rules.
├── 📄 gen_doc.py                     # [Python] A utility script used to generate the `LabLens_Documentation.pdf` file using the `fpdf` library.
├── 📄 requirements.txt               # [Text] Lists the Python dependencies required to run the backend (e.g., `fastapi`, `uvicorn`, `anthropic`, `fpdf`).
│
├── 📄 README.md                      # [Markdown] The main project documentation file containing setup instructions and a brief overview.
├── 📄 CLAUDE.md                      # [Markdown] Internal instructions and coding guidelines for AI assistants working on the project.
├── 📄 DEMO.md                        # [Markdown] Notes or scripts regarding the project demonstration.
│
├── 📄 LabLens_Documentation.pdf      # [PDF] The comprehensive technical documentation covering the architecture, math, and features of the application.
├── 📄 LabLens_Project_Report (1).pdf # [PDF] A larger, detailed project report/presentation file.
│
└── 📂 venv/                          # [Directory] Python Virtual Environment containing installed packages (auto-generated, should not be manually edited).
```

### Key Technologies
- **Frontend**: Vanilla HTML/CSS/JS (Zero frameworks for maximum speed)
- **Computer Vision**: Google MediaPipe Hands (Client-side tracking)
- **Backend**: Python + FastAPI
- **Database**: SQLite3
- **AI Integration**: Anthropic Claude API (via `app.py`)
